# Kickoff

## Objective

Reproduce the complete public Amber Walker Events website in maintainable Next.js with locally organized, clear media and independently verified desktop/mobile fidelity.

## Start condition

The user approves `.genesis/PLAN.md`.

## First BUILD loop

M0 — build the route/content/media/reference capture pipeline and freeze its output before implementing UI.

## Scope guard

Do not redesign, omit routes, silently replace media, connect a live form destination, or deploy without explicit scope/authority.
