Definition of Done

1. Cognitive job

  1. User and outcome: the client needs the complete Amber Walker Events public site reproduced in maintainable Next.js while retaining its recognizable visual identity and content.
  2. Primary reasoning challenge: infer reusable templates and exceptions from a 94-route Wix site without flattening meaningful visual differences.
  3. Inputs: the live website, its public sitemaps, public media, rendered desktop/mobile states, and user authorization.
  4. Outputs: local Next.js source, organized local media, complete route/content data, functional interactions, and reproducible fidelity evidence.
  5. Failure signals: missing routes/assets/copy, hotlinked owned media, generic redesign, broken responsive behavior, nonfunctional interactions, or maker-only verification.

2. Binary gates

  • PASS only if all 94 inventoried routes return the expected content.
  • PASS only if a clean install, lint, typecheck, tests, and production build succeed.
  • PASS only if owned media is local, correctly referenced, and free of broken requests.
  • PASS only if desktop/mobile visual checks meet the approved threshold.
  • PASS only if navigation, galleries, videos, links, and form validation work.
  • PASS only if an independent verifier—not the maker—records the final result.

3. Milestones

  1. M0: reproducible reference, route, content, screenshot, and media baseline.
  2. M1: Next.js foundation and shared responsive shell.
  3. M2: core and service landing pages.
  4. M3: all 65 location/service pages.
  5. M4: blog, portfolio galleries, and video behavior.
  6. M5: SEO, forms, performance, and accessibility.
  7. M6: independent full-site fidelity verification.
