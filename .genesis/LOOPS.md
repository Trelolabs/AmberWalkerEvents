# Development Loops

For each milestone:

1. EXISTENCE — confirm prerequisite files, source evidence, and exact demo command exist.
2. BUILD — implement only the active milestone and update `CURRENT.md` with decisions and evidence.
3. CHECK — run targeted lint, type, functional, content, and visual checks; repair failures.
4. VERIFY — use a separate verifier context to compare the result with the milestone gate and frozen reference.
5. FREEZE — record passed evidence and respect the milestone's freeze boundary before moving forward.

`DONE.html` is locked during a loop. Scope changes require user agreement and a plan update before implementation.
